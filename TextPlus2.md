# TextPlus2
The successor to (https://github.com/Nan0MK/TextPlus).
The upgraded version of TextPlus with new features, looks, and performance.

## Features
Support for rendering text files with syntax highlighting,
Special rendering for markdown files,
Plain text file support,

## Looks
New default graphical style with light and dark modes,
Custom Icons,

## Performance
Keeping the code running fast for fast startup, running, and closing times.


## Standard features
copy, cut, paste, undo, redo, find, find and replace.
Standard (non-modal) keybinds for all.
